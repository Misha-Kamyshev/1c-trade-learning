# Учебная конфигурация 1С: закупки, продажи, взаиморасчёты

## Возможности
- Приход и расход товара, оплаты и поступления денег
- Взаиморасчёты по документам с контролем переплаты
- Управляемые блокировки для многопользовательской работы
- Отчёты: остатки товаров, взаиморасчёты, документы по контрагентам

## Структура конфигурации
Справочники, документы, регистры (таблица или список)

## Как запустить
1. Скачать .cf из Releases
2. Создать пустую базу, загрузить конфигурацию
(или развернуть .dt с демо-данными)

## Технологии
1С:Предприятие 8.3.27, управляемое приложение, язык запросов
